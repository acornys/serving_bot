# 1007 v3 수정본 (실물 테스트 전 · 제안본)

**10/7 주행 테스트에서 나온 문제점(벽에 박고 계속 전진 · 빙글빙글 반복 · 실패인데 "완료" 표시)을 수정한 버전.**

10/7 오후 테이블 5개 맵에서 쓴 `robot5_manager.py` 에 안전장치 3가지를 넣은 것.
좌표 · 모드 동작 · STOP 은 그대로. 바꾼 줄은 코드에 `[수정 v3-번호]` 주석으로 표시.

| 번호 | 바꾼 것 | 이유 |
|---|---|---|
| v3-1 | 포기 조건: 한 번 이동이 60초를 넘거나 복구 동작(빙글빙글)이 2번을 넘으면 목표 취소 + 정지 | 벽에 박고 계속 전진 · 끝없이 빙빙 도는 것을 끊음 |
| v3-2 | 실패 문구: 도착 못 하면 `[주문 실패]` | 실패했는데 "완료" 라고 찍혔음 |
| v3-3 | 재시도: 실패하면 그 자리에서 같은 목표를 1번 다시 보냄 | 지금 위치에서 경로를 새로 짬 |

## 주의

**실물 로봇에서 아직 안 돌려 봄.** 문법 확인(`python3 -m py_compile`)만 함.

60초 · 2번 · 1번은 임시 값. 맨 위 `NAV_TIMEOUT_SEC` `MAX_RECOVERIES` `RETRY_COUNT` 에서 조절.

2번 테이블 문제의 원인을 고치는 것은 아님 (증상을 끊어 주는 것).

파일 하나만 있음. 쓰려면 패키지의 `robot5_manager.py` 를 이 파일로 바꾸기.
